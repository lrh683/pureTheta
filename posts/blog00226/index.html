微软与OpenAI的协议已'演变'为优先供应新算力

Microsoft 和 OpenAI 周二宣布，他们已经调整了合作伙伴关系，以便 OpenAI 可以访问竞争对手的计算。

Microsoft 表示，新协议“包括对新算力排他性的更改，转向 Microsoft 拥有优先购买权 （ROFR） 的模式”。“为了进一步支持 OpenAI，Microsoft 已批准 OpenAI 构建算力，主要用于模型的研究和训练。”

而合作关系的基础几乎保持不变（持续到 2030 年）——Microsoft 保留了 在 Copilot 等产品中使用OpenAI技术的专有权，而 访问OpenAI 的 API 仍然是 Azure 的专有权。他们将保持双向收入分享安排（据报道，Microsoft 获得了 OpenAI 20% 的收入）。在此调整前，OpenAI 被锁定为仅能使用 Microsoft 的 Azure 云基础设施来满足其计算需求。

该消息是在 Arm、Microsoft、Nvidia、Oracle 和 OpenAI 宣布成立合资企业以在美国建立一个名为 Starbase 的数据中心系统之后发布的。

OpenAI 希望构建的模型及其希望服务的用户群需要数十亿美元的计算。此前有报道称，一些 OpenAI 股东认为 Microsoft 的行动不够快，无法为 OpenAI 提供计算能力，因此这家初创公司在 6 月份（在 Microsoft 的祝福下）与 Oracle 合作提供必要的计算。

在 OpenAI 首席执行官山姆·阿尔特曼 （Sam Altman） 被短暂赶出公司后，关于 Microsoft 和 OpenAI 面临关系困境的讨论很多，引起了非常公开的戏剧性事件。《纽约时报》报道称，由于 OpenAI 的财务压力、对稳定性的担忧以及两家公司员工之间日益严重的摩擦，这种关系变得越来越紧张。

去年 3 月，Microsoft 以 6.5 亿美元的价格聘请了 Inflection 首席执行官穆斯塔法·苏莱曼 （Mustafa Suleyman） 以及 Inflection 的大多数员工来领导其消费者人工智能工作。据《纽约时报》报道，此举尤其激怒了一些 OpenAI 领导层，包括阿尔特曼。

"OpenAI与微软的协议还包含一个不寻常的退出条款：如果OpenAI开发出通用人工智能（AGI），它可以在此之后切断微软对某些OpenAI最强大模型的访问权限。据报道，AGI被定义为能够产生超过1000亿美元利润的系统。这一条款最初旨在防止如此强大的AI被商业化，但OpenAI现在正考虑取消这一条款，可能是为了获取更多来自微软的资金支持。"

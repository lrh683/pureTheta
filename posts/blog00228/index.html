OpenAI 和软银正在成立一家价值 5000 亿美元的 AI 数据中心公司 

“星际之门项目”正在德克萨斯州开始扩建，甲骨文、MGX、Microsoft、Nvidia 和 Arm 参与其中。

Image: The White House (YouTube)

白宫新闻发布会上透露了一项为人工智能构建数据中心系统的计划，孙正义、山姆·奥特曼和拉里·埃里森与唐纳德·特朗普一起宣布了星际之门项目。软银、OpenAI 和甲骨文（分别）以及 MGX 被列为未来四年 5000 亿美元投资的“初始股权资助者”，“为美国的 OpenAI 构建新的人工智能基础设施”。
（注：MGX为一中东AI基金）

根据 OpenAI 的一份声明，“Arm、Microsoft、NVIDIA、Oracle 和 OpenAI”是最初的技术合作伙伴，随着对全国其他站点进行评估，“目前正在”从德克萨斯州开始扩建。“它还表示，”Oracle、NVIDIA 和 OpenAI 将密切合作构建和运营这个计算系统。
https://openai.com/index/announcing-the-stargate-project/

另外，Microsoft 宣布更新与 OpenAI 的合作伙伴关系，称他们交易的关键要素将持续到 2030 年，使用OpenAI 知识产权、收入共享和其他排他性协议都将继续执行。
https://blogs.microsoft.com/blog/2025/01/21/microsoft-and-openai-evolve-partnership-to-drive-the-next-phase-of-ai/

Microsoft 表示 OpenAI 已经做出了“新的大型 Azure 承诺，将继续支持所有 OpenAI 产品和培训”。然而，他们对新产能的独家安排正在发生变化，现在调整为 Microsoft 对 OpenAI 建设新产能拥有优先供应权。
https://www.theverge.com/e/24113047

在宣布该项目的新闻发布会上（自去年初以来一直传闻），孙正义和阿尔特曼直接与特朗普交谈，坚称该项目只是因为他的选举胜利而发生的。

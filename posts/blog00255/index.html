前沿｜Open AI与Anthropic的军工合作立场比较

2025-01-12
内容来源：Perplexity.ai 辅助整合，Claude辅助翻译。


简介

OpenAI 和 Anthropic 这两家著名的人工智能公司，正在越来越多地参与美国国防，并采取了截然不同的策略。 OpenAI 已从最初禁止军事应用转向寻求多个合同，包括与 Carahsoft 和国防部的合作伙伴关系，而 Anthropic 通过与 Palantir 和 AWS 的战略联盟采取了更加结构化和透明的方法，以加强国防行动。
（备注：
Carahsoft是一家总部位于美国弗吉尼亚州的IT解决方案提供商，成立于2004年。该公司主要充当大型科技公司与地方和联邦政府部门之间的中介，帮助政府机构获取各种技术产品和服务。Carahsoft的主要客户包括美国国防部、国家航空航天局（NASA）以及其他联邦机构。

Palantir Technologies是一家美国软件与服务公司，成立于2003年，总部位于科罗拉多州丹佛市。该公司专注于大数据分析，主要为政府和金融机构提供解决方案。Palantir的核心产品包括：Palantir Gotham：专为政府和军事客户设计，主要用于情报和防御分析。Palantir Foundry：为商业客户提供的数据整合和分析平台。Palantir Apollo：用于简化和加速软件更新与维护的平台。
早期关注Palantir的早期业务主要集中在美国情报界，特别是反恐领域。公司以其技术支持美国军方的行动而闻名，例如协助定位并击毙基地组织首领本·拉登。此外，Palantir的软件被用于处理复杂的数据集，以帮助识别潜在威胁和进行决策。
）

Open AI

OpenAI 最近与美国军方和国防部门的合作标志着该公司在与国防机构合作方面的立场发生了重大转变。
  • OpenAI 与备受争议的国防承包商 Carahsoft 合作，进军国防部门（https://www.aldianews.net/en/leadership/corporate/openai-dod ）
  • 该公司的 GPT-4 模型是 Microsoft、Palantir 以及美国各个国防和情报机构合作伙伴关系的核心。
    （https://finance.yahoo.com/news/openai-quietly-pitching-products-u-145321695.html  
    https://fortune.com/2024/10/17/openai-is-quietly-pitching-its-products-to-the-u-s-military-and-national-security-establishment/）
  • OpenAI 和国防部正在合作开发基于人工智能的网络安全技术 ，OpenAI 取消了之前的军事应用禁令，为与国防部更广泛的合作打开了大门。 
    https://www.govconwire.com/2024/01/openai-lifts-military-ban-opens-doors-to-dod-for-cybersecurity-collab/
  • 该公司首次确认向美国军事作战司令部出售产品，特别是 AFRICOM（美国非洲司令部），与 AFRICOM 的合作代表了从以前的探索性研究到在执行作战任务的指挥中使用的转变。
    （https://theintercept.com/2024/10/25/africom-microsoft-openai-military/）
    （美国非洲司令部（AFRICOM）是负责监督五角大楼在非洲的军事行动的机构。其主要任务包括与非洲国家的军事合作、反恐行动、以及人道援助和灾害响应等。）

这些进展表明 OpenAI 越来越多地参与国防部门，从网络安全合作到潜在的战斗相关应用，这标志着该公司与军事和情报机构的关系发生了重大演变。
Anthropic 
一直以来采取了更加框架性和透明的方式与美国国防部门合作，重点关注特定的战略合作伙伴关系，为情报和军事机构提供人工智能功能：
    • 与 Palantir 和 Amazon Web Services (AWS) 合作，向美国国防和情报机构提供 Claude 系列人工智能模型。
      （https://www.thedailyupside.com/technology/artificial-intelligence/ai-startup-anthropic-to-partner-with-palantir-aws-to-sell-to-intelligence-and-defense-agencies/）
    • 专注于通过人工智能驱动的解决方案增强美国国防行动
      （https://opentools.ai/news/anthropic-joins-forces-with-palantir-and-aws-to-bring-ai-to-us-defense）
    • 维持清晰的协作框架，有可能允许在国防应用中更加受控和合乎道德地使用人工智能
      （https://observer.com/2024/11/openai-rival-anthropic-provide-ai-models-dod/）

    主要差异


    OpenAI 和 Anthropic 在与美国军事和国防部门的合作中采取了不同的策略，反映了平衡商业机会与道德考虑的不同方法。以下是它们主要战略差异的简要比较：

    OpenAI 奉行逐步扩展到国防部门的战略，参与多项合同和合作，包括与 Carahsoft 和国防部就网络安全项目建立合作伙伴关系 。相比之下，Anthropic 选择了一种更加结构化的方法，与 Palantir 和 AWS 建立了特定的合作伙伴关系，向美国国防机构提供其 Claude AI 模型。虽然 OpenAI 一直在悄悄向各个军事和情报机构推销其产品 , Anthropic 对于通过战略联盟为国防部门服务的意图更加透明 。

    两方初始军工合作立场

    OpenAI 最初在其使用政策中包含了一项条款，明确禁止将其技术用于军事目的 。这一立场与公司确保通用人工智能造福全人类的最初使命是一致的。然而，OpenAI 于 2024 年初悄然取消了这一禁令，标志着其国防相关工作方式的转变 。https://theintercept.com/2024/01/12/open-ai-military-ban-chatgpt/

    另一方面，Anthropic 从一开始就没有公开表示反对军事应用。该公司专注于开发安全且符合道德的人工智能系统，但并未明确排除潜在的国防相关用例。这种更加开放的立场可能促进了 Anthropic 后来与 Palantir 等国防型公司的结构化合作伙伴关系。
    https://fortune.com/2024/10/17/openai-is-quietly-pitching-its-products-to-the-u-s-military-and-national-security-establishment/

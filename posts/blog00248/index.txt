style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">该研究结果发表在 arXiv 预印本服务器上，AlloyBert 的软件现已在 GitHub 上可供使用。</span></span></p><p 16px;">&nbsp;</span></span></span></section><p><span leaf=""><br  /></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;font-weight: bold;">附录：</span></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><br  /></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;font-weight: bold;">一、DFT 在这篇文章中是指密度泛函理论（Density Functional Theory）。</span></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><br  /></span></p><ol style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);" class="list-paddingleft-1"><li style="-webkit-font-smoothing:antialiased;box-sizing:border-box;-webkit-tap-highlight-color:rgba(0, 0, 0, 0);"><strong style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><span leaf=""><span textstyle="" style="font-size: 16px;font-weight: normal;">基本原理</span></span></strong></li><ul style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);" class="list-paddingleft-1"><li style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><section style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">密度泛函理论是一种研究多电子体系电子结构的量子力学方法。它的基本思想是，体系的基态物理性质可以通过电子密度分布函数来唯一确定。简单来说，电子密度就像是一个 “指纹”，通过它可以了解系统的各种特性。</span></span></section></li><li style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><section style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">例如，在一个原子或分子中，电子是在原子核的吸引下运动的。DFT 通过求解电子密度来描述电子的行为，而不是像传统的量子力学方法那样直接求解多电子波函数（因为求解多电子波函数非常复杂，随着电子数目的增加，计算量呈指数增长）。</span></span></section></li></ul><li style="-webkit-font-smoothing:antialiased;box-sizing:border-box;-webkit-tap-highlight-color:rgba(0, 0, 0, 0);"><strong style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><span leaf=""><span textstyle="" style="font-size: 16px;font-weight: normal;">在材料科学中的应用（如合金研究）</span></span></strong></li><ul style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);" class="list-paddingleft-1"><li style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><section style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">在合金性能研究中，DFT 可以用于计算合金的各种物理性质。例如，它可以帮助确定合金的晶格结构、电子态密度等。</span></span></section></li><li style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><section style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">从原子层面看，合金是由不同种类的金属原子组成的，DFT 可以计算原子间的相互作用能，从而预测合金的稳定性。通过这种方式，可以了解合金在不同条件下（如不同温度、压力）是否会发生相变，这对于材料的设计和应用非常重要。</span></span></section></li><li style="-webkit-font-smoothing: antialiased;box-sizing: border-box;-webkit-tap-highlight-color: rgba(0, 0, 0, 0);"><section style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">然而，正如文章中提到的，DFT 计算对于复杂合金来说可能非常耗时，因为它需要大量的计算资源来准确地求解电子密度等相关物理量。</span></span></section></li></ul></ol><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><br  /></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;font-weight: bold;">二、MLM</span></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">掩码语言模型（Masked Language Model，MLM）是自然语言处理中的一种重要模型架构。</span></span></p><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><br  /></span></p><section><span leaf=""><span textstyle="" style="font-size: 16px;">在训练过程中，它会随机地将输入文本中的一些单词或标记替换为特殊的掩码标记（例如 [MASK]），模型的任务就是根据文本的上下文来预测这些被掩码的位置原本应该是什么单词。例如，对于句子 “我 [MASK] 去超市买东西”，模型要基于 “我”“去超市买东西” 等上下文信息来预测 [MASK] 处可能的词汇，可能是 “要”“想” 等。</span></span></section><p style="margin-bottom: 0px;margin-top: 0px;line-height: 1.6em;"><span leaf=""><span textstyle="" style="font-size: 16px;">这种训练方式使得模型能够学习到文本中单词之间的语义和语法关系，从而增强对语言的理解和生成能力。像 BERT（Bidirectional Encoder Representations from Transformers）等模型就广泛采用了 MLM 技术进行预训练，通过大量的文本数据训练，模型可以捕捉到丰富的语言知识和语义信息，在后续的自然语言处理任务如文本分类、情感分析、问答系统等中表现出良好的性能。</span></span></p><p style="display: none;"><mp-style-type
